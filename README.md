# Kunnected Living Website

MASTER PROMPT

Project Overview

Design and develop a world-class, enterprise-grade corporate website for Kunnected Living Facilities Management Services LLC (Kunnected FM).

This is not a startup landing page, not a SaaS template, and not a generic facilities management website.

The final result should look like it was designed by a top creative agency for a Fortune 500 company.

Think of the quality and craftsmanship found on websites like:

Apple

Stripe

Linear

Notion

CBRE

JLL

Siemens Smart Infrastructure

Foster + Partners

Every section should feel custom-designed with unique layouts, premium typography, meaningful whitespace, refined animations, and excellent visual hierarchy.

The website should immediately communicate:

Trust

Professionalism

Precision

Operational Excellence

Innovation

Student-first Facilities Management

The overall experience should make visitors feel they are interacting with a company that manages world-class educational campuses. This positioning aligns with the company's purpose of creating connected, seamless campus environments and enabling better student experiences.

Design Philosophy

Do NOT use common website templates.

Every page should have:

• Custom layouts

• Asymmetrical compositions

• Premium spacing

• Large typography

• High-end photography

• Elegant animations

• Modern editorial design

• Smooth transitions

• Premium interaction design

No section should look copied from another website.

Each section must feel handcrafted.
